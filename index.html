Release Notes

Stripes Movie Database — spreadsheet history

Legacy spreadsheet versions, separate from Top Shelf releases. All entries by Adam Lauer.

1.5.0 · 2024-09-18

  • Updated Watch column format for better sorting.
  • Improved scripts: variable handling/scoping, success logic in movie updates, and a fix for the optional date-update column.

1.4.0 · 2024-06-19

  • Added a validation check in column A of Movies to ensure each row has its formulas.
  • Added Loop and Time Travel manual pivots.

1.3.0 · 2023-11-13

  • Pivots: added Actors and Directors groupings, thresholds and counts, and better formatting.
  • UpdatePivots: added a threshold on gets, refactored to be more generic, and added sortPivots after updating.

1.2.0 · 2023-11-12

  • Movies: added duplicate detection and resolved existing issues; changed 💯 rating to 100!; improved How column formula.

1.1.0 · 2023-11-11

  • Added a Notes tab with a programming-esque information format.
  • Movies: better formatting. Pivots: column groupings and better formatting.
  • UpdateUtilities: combined Constants and Utilities, refactored and cleaned up syntax, added SheetNames, Columns, and ColorHex.
  • UpdateMovies and UpdatePivots: refactored and cleaned up syntax.

1.0.0 · 2023-11-10

  • Initial creation with Movies and Pivots tabs.
